# 🍰 Brownles Boutique

Sitio web corporativo desarrollado para una boutique de repostería artesanal premium.  
El proyecto combina diseño elegante, experiencia de usuario optimizada y buenas prácticas modernas de desarrollo frontend.

🔗 Demo en producción: [https://brownles.vercel.app/](https://brownles.vercel.app/)

---

## 🎯 Propósito del Proyecto

Brownles Boutique fue desarrollado con un doble enfoque:

- 🧁 Presentar una marca de repostería con identidad visual sólida y profesional.
- 💼 Aplicar estándares reales de desarrollo frontend listos para producción.

El proyecto simula un entorno profesional donde se priorizan:
- Rendimiento
- Escalabilidad
- SEO técnico
- Arquitectura limpia
- Despliegue en producción

---

## 🚀 Stack Tecnológico

- React
- TypeScript
- Vite
- React Router DOM
- React Helmet Async (SEO dinámico)
- CSS moderno y diseño responsivo
- Deploy en Vercel

---

## 🧠 Enfoque Técnico

El sitio está construido como una SPA (Single Page Application), con manejo de rutas mediante React Router y configuración personalizada en Vercel para evitar errores 404 al recargar páginas internas.

Se implementó un sistema de SEO dinámico que incluye:

- Meta tags únicos por página
- Canonical URLs
- Open Graph (Facebook, WhatsApp)
- Twitter Cards
- JSON-LD (Schema.org)
- Optimización semántica con jerarquía de encabezados

Esto permite que el sitio no solo sea visualmente atractivo, sino también correctamente indexable por motores de búsqueda.
